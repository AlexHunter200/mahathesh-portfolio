## 🚀 Deployment

This portfolio can be deployed to:
- **GitHub Pages**: Push to main branch and enable Pages in repo settings
- **Netlify**: Connect repository and auto-deploy on push
- **Vercel**: Similar Netlify workflow for serverless deployment
- **Traditional Hosting**: Copy files via FTP/SSH

### GitHub Pages Quick Start
1. Repository Settings → Pages
2. Select "Deploy from branch"
3. Choose "main" branch and "/root" folder
4. Save and wait for deployment (usually < 1 minute)

## 📝 Usage

### Interactive Features
- **Mobile Menu**: Click hamburger icon to toggle navigation
- **Position Nodes**: Click any position on tactical pitch to view details
- **Download PDF**: Print-to-PDF using browser's print function
- **Scroll Navigation**: Links highlight as you scroll through sections

### Customization

#### Update Player Info
Edit `index.html` to update:
- Name and age
- Nationality and position
- Academy name
- Club history
- Tournament achievements

#### Customize Colors
Modify `:root` CSS variables in `style.css`:
```css
:root {
    --primary-color: #1e40af;  /* Change primary blue */
    --secondary-color: #f59e0b; /* Change secondary orange */
    --accent-color: #ec4899;    /* Change pink accent */
}
```

#### Update Images
Replace image files in `assets/images/`:
- `IMG_8805.jpg`: Main profile photo
- `Skill.png`: Winger Topps card
- `Skill (2).png`: Club Topps card
